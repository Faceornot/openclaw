《泰坦尼克号幸存者预测》竞赛研究报告

一、实验背景

泰坦尼克号幸存者预测是 Kaggle 平台上的经典数据挖掘竞赛之一。该竞赛要求参赛者根据乘客的基本信息，如舱位等级、性别、年龄、票价、家庭成员数量和登船港口等特征，预测乘客在泰坦尼克号事故中是否幸存。该任务本质上属于典型的二分类问题，适合用于练习数据预处理、探索性数据分析、特征工程、模型构建、模型评估与结果分析等数据挖掘的完整流程。

本次研究在视频讲解的基础流程上进行了优化与改进，重点围绕数据分析方法、特征工程策略、模型选择及评估方式展开，目标是在保证分析合理性的前提下，提高模型预测精度，并完成 Kaggle 平台提交与结果分析。

二、实验目的

  1. 学习并掌握 Titanic 数据集的基本分析流程；
  2. 对视频中的基础数据分析流程进行优化；
  3. 对基础模型进行改进，提高预测效果；
  4. 在 Kaggle 平台提交预测结果并观察 leaderboard 排名；
  5. 总结模型表现及影响结果的主要因素，形成完整研究报告。

三、数据分析优化与实现

3.1 原始分析流程存在的不足

视频中的基础流程通常包括读取数据、查看缺失值、使用简单方式填补缺失数据、对类别变量进行编码，再训练一个基础分类模型。这种流程能够完成基本任务，但仍有以下不足：

  • 缺失值处理较粗糙，通常直接使用整体均值、中位数或众数填补；
  • 对特征之间的潜在关系挖掘不够深入；
  • 仅使用原始字段，缺乏有效的特征工程；
  • 模型评估方式较为单一，结果稳定性不足；
  • 代码流程较分散，不利于复现和后续优化。

因此，有必要对数据分析流程进行系统优化。

3.2 缺失值处理优化

在 Titanic 数据集中，Age、Cabin、Embarked 和 Fare 等字段存在不同程度的缺失。若直接采用整体填补，会忽略不同群体的分布差异。

本研究做出了如下优化：

  • 对 Age 按 Title 和 Pclass 进行分组后使用中位数填补；
  • 对 Fare 按 Pclass 分组后使用中位数填补；
  • 对 Embarked 使用众数填补；
  • 对 Cabin 不直接删除，而是提取“是否有舱位记录”以及“舱位首字母”等衍生特征。

这样做的原因在于，不同舱位等级、不同称谓乘客的年龄分布和票价分布具有明显差异，分组填补可以更真实地反映数据结构，从而减少信息损失。

3.3 特征工程优化

相比只使用原始字段，本研究进一步构造了多个更具解释力的特征：

  1. Title（称谓）：从 Name 字段中提取 Mr、Mrs、Miss、Master 等称谓，并将出现次数很少的称谓合并为 Rare；
  2. FamilySize（家庭规模）：由 SibSp + Parch + 1 构造，表示乘客同行家庭成员数量；
  3. IsAlone（是否独自出行）：根据 FamilySize 判断乘客是否独自出行；
  4. CabinKnown（是否有舱位信息）：表示该乘客是否存在舱位记录；
  5. CabinLetter（舱位首字母）：从舱位编号中提取首字母，用于表示舱位区域特征。

这些衍生特征能够更好地反映乘客的身份信息、家庭关系和舱位条件，相比直接使用原始字段更有利于模型学习。

3.4 探索性数据分析优化

在基础分析中，通常只关注性别和舱位等级对生存率的影响。本研究进一步关注了以下因素：

  • 性别与生存率关系；
  • 舱位等级与生存率关系；
  • 年龄与生存率关系；
  • 票价与生存率关系；
  • 称谓与生存率关系；
  • 家庭规模与生存率关系；
  • 是否独自出行与生存率关系。

通过更全面的探索性分析，可以为特征选择和模型改进提供依据。

3.5 数据预处理流程标准化

为了避免训练集和测试集处理方式不一致，本研究使用 Pipeline 和 ColumnTransformer 对数据预处理进行统一管理。具体包括：

  • 数值特征：缺失值填补 + 标准化；
  • 类别特征：缺失值填补 + 独热编码。

这样做能够提高实验流程的规范性、降低数据泄漏风险，并提升结果的可复现性。

四、数据挖掘模型改进与原因分析

4.1 基础模型及其不足

在视频中的基础方法里，常见模型包括逻辑回归、决策树和简单随机森林。逻辑回归虽然具有训练速度快、可解释性较强等优点，但其本质上属于线性模型，对复杂的非线性关系和特征交互作用表达能力有限。

4.2 模型改进方案

为了提高预测性能，本研究在基础模型之外，比较并引入了如下模型：逻辑回归、随机森林和梯度提升树模型。

其中，在本次 5 折交叉验证实验中，不同模型的结果如下：

  • LogisticRegression：0.83166
  • RandomForest：0.82940
  • GradientBoosting：0.82044

从结果可以看出，逻辑回归模型取得了最高的平均交叉验证准确率 0.83166，表现略优于随机森林和梯度提升模型。因此，本研究最终选取逻辑回归作为提交模型，并基于该模型生成 submission.csv 文件用于 Kaggle 提交。

4.3 交叉验证的引入

本研究采用了 5 折交叉验证方法，对模型在训练集上的表现进行更稳定的评估。交叉验证能够更客观地评价模型泛化能力，减少偶然划分带来的结果波动，并便于比较不同模型之间的优劣。

4.4 模型改进原因总结

综合来看，模型改进主要基于以下考虑：基础模型对复杂关系表达不足、Titanic 数据集具有一定的非线性特征、集成模型在结构化数据分类任务中通常表现更优、更稳定的评估方式有助于选择更优模型。与此同时，本次实验结果也说明，并不是越复杂的模型就一定越好，在当前特征工程和数据规模条件下，逻辑回归反而表现最优。

五、模型结果分析说明

结合数据分析和模型训练结果，可以发现 Sex、Pclass、Age、Fare、Title 以及 FamilySize 等特征对生存预测影响较大。这说明在数据理解基础上构造更有意义的衍生特征，对模型表现有明显帮助。

通过比较不同模型的交叉验证表现可以得到如下结论：逻辑回归模型结果较稳定，并在本次实验中取得最优交叉验证分数；随机森林能较好处理非线性关系，但在本实验中略低于逻辑回归；梯度提升模型具有较强表达能力，但在当前参数设置下表现不如前两者。

尽管模型经过优化后性能有所提升，但仍可能出现预测误差，原因包括训练样本数量有限、Cabin 等特征缺失严重、部分真实影响幸存的因素未被记录，以及测试集与训练集之间可能存在一定分布差异。

七、实验总结

本次研究在视频讲解基础上，对 Titanic 幸存者预测任务进行了较为系统的优化。主要改进包括：使用更合理的缺失值填补方法；增加了称谓、家庭规模、是否独行、舱位信息等特征工程；对探索性分析进行了扩展；使用 Pipeline 和 ColumnTransformer 统一数据预处理流程；引入多模型比较和交叉验证，提高模型效果与评估稳定性；完成 Kaggle 平台提交，并获得实际排行榜分数与排名。

实验表明，在数据挖掘任务中，模型性能的提升并不仅仅依赖于更换模型，更重要的是对数据本身进行深入理解，并结合业务含义进行合理的特征构造。
